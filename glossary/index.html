名詞解釋 (Glossary)

整理本指南中出現的關鍵術語，方便您快速查閱。

一、核心名詞釋義

💡

Server-Sent Events (SSE)

一種基於 HTTP 的推播技術，允許伺服器將資料即時、單向地推播給瀏覽器。常用於即時通知或 AI 聊天機器人的打字機效果。

ℹ️

EventSource

瀏覽器內建用來接收 SSE 資料流的 JavaScript API，能夠自動發起連線、處理斷線重連，並透過 onmessage 事件接收資料。

ℹ️

Node.js

建立在 Chrome V8 引擎上的 JavaScript 執行環境，擁有非阻塞 I/O 與事件驅動的特性，非常適合建立高效能的網路伺服器與 SSE 推播服務。

ℹ️

NVM (Node Version Manager)

Node.js 的版本管理工具，讓開發者可以在同一台電腦上輕鬆安裝並切換多個不同版本的 Node.js，避免不同專案間的版本衝突。

ℹ️

C99 引擎 (C99 Engine)

指以 C99 標準撰寫的即時插補運算核心程式 (例如 rtcp_engine.exe)。C 語言具備極高的執行效能與底層控制力，能滿足 1 kHz 甚至更高頻率的即時五軸插補運算需求。

二、名詞特徵對照表

技術名詞 通訊方向 基礎協定 主要用途
SSE 單向推播 HTTP 即時通知、資料更新、狀態監控
WebSocket 雙向通訊 WebSocket 即時對戰遊戲、聊天室、協作編輯
Long Polling 單向 (模擬) HTTP 舊系統相容方案
