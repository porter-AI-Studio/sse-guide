Windows 環境建置：Node.js 安裝教學

了解如何在 Windows 上快速建置 Node.js 開發環境，為後續的 SSE 實戰打下基礎。

推薦的安裝方式：NVM for Windows

雖然您可以直接從官方網站下載 .msi 安裝檔，但實務上我們強烈建議使用 NVM (Node Version Manager) 來管理 Node.js 版本。這可以讓您在不同的專案間切換所需的 Node.js 版本，避免版本衝突。

⚠️

注意： 安裝 NVM for Windows 之前，請務必先將系統中已有的 Node.js 解除安裝，以免路徑衝突。

Step 1. 下載並安裝 nvm-windows

前往 nvm-windows Releases 頁面，下載 nvm-setup.exe，然後按照提示完成安裝。

Step 2. 安裝 Node.js

打開 PowerShell (建議使用系統管理員身分執行)，輸入以下指令來查詢可安裝的版本：

nvm list available

挑選一個最新的 LTS (長期支援) 版本，例如 24.9.0，然後安裝：

(base) PS C:\Users\porte> node -v
v24.9.0
(base) PS C:\Users\porte> nvm install 24.9.0
Installation complete.
If you want to use this version, type:

nvm use 24.9.0

安裝完成後，告訴系統你要使用這個版本：

nvm use 24.9.0

Step 3. 驗證安裝

最後，確認 Node.js 與 npm 是否已正確安裝並設定在路徑中：

(base) PS C:\Users\porte> node -v
v24.9.0
(base) PS C:\Users\porte> npm -v
11.6.4

如果能順利印出版本號，恭喜您的環境已經準備就緒！
