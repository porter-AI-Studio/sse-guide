簡易實戰(參考觀念)：9*9 乘法表

不再只是傳送簡單的時間！這次我們將實作一個更真實的場景：使用 Node.js 執行外部程式（如 C 語言編譯的 9*9 乘法表程式），並透過 SSE 將其執行結果即時串流給前端。

1. 情境介紹

在實務上，我們常常需要透過 Node.js 執行一段耗時的外部任務（例如機器學習模型推理、或是背景的 C/C++ 程式），並希望讓前端即時看到「執行進度」。這個情境非常適合使用 SSE！

我們假設您有一個 multiplication.exe（9*9 乘法表產生器），我們將用 Node.js 的 child_process.spawn 啟動它，並將它輸出的每一行結果推播給所有連接的網頁客戶端。

1. 系統架構與流程

為了讓您更清楚我們接下來要撰寫的程式碼在做什麼，請先參考以下架構圖：

  sequenceDiagram
      participant C as 客戶端 (Browser)
      participant S as 伺服器 (Node.js)
      participant P as 外部程式 (C 執行檔)
      
      Note over C,S: 1. 建立推播通道
      C->>S: GET /api/events (建立 SSE 連線)
      S-->>C: 200 OK (Content-Type: text/event-stream)
      
      Note over C,S: 2. 任務控制指令群
      C->>S: POST /api/start (手動步進開始)
      C->>S: POST /api/run-all (自動全部執行)
      C->>S: POST /api/continue (繼續下一步)
      C->>S: POST /api/end (強制結束)
      S->>P: 依據指令透過 spawn() 或 stdin 互動
      S-->>C: data: [type=status, payload=RUNNING 或 WAITING_INPUT]

      
      Note over S,P: 3. 即時攔截輸出並推播
      P-->>S: stdout 輸出: 1*1=1
      S-->>C: data: [type=result, payload=1*1=1]
      P-->>S: stdout 輸出: 1*2=2
      S-->>C: data: [type=result, payload=1*2=2]
      
      Note over S,P: 4. 任務結束
      P->>S: process exited
      S-->>C: data: [type=status, payload=ENDED]

2. 初始化專案與安裝套件

在您的終端機中建立新資料夾並初始化專案：

mkdir sse-multiplication
cd sse-multiplication
npm init -y
npm install express

3. 撰寫伺服器端程式碼 (server.js)

建立 server.js，這裡我們整合了 SSE 端點與 spawn，當接收到客戶端請求時，就會建立 SSE 連線並將子行程的輸出轉換為 SSE 事件發送。

const express = require('express');
const { spawn } = require('child_process');
const path = require('path');

const app = express();
app.use(express.static('public'));

let sseClients = [];

// 發送 SSE 訊息的共用函數
function broadcastSSE(type, payload) {
    const data = JSON.stringify({ type, payload });
    sseClients.forEach(client => {
        client.write(`data: ${data}\n\n`);
    });
}

// SSE Endpoint：管理連線
app.get('/api/events', (req, res) => {
    res.setHeader('Content-Type', 'text/event-stream');
    res.setHeader('Cache-Control', 'no-cache');
    res.setHeader('Connection', 'keep-alive');

    // 告知連線成功
    res.write(`data: ${JSON.stringify({ type: 'connection', payload: 'connected' })}\n\n`);
    
    sseClients.push(res);
    console.log(`新客戶端連線，目前總數: ${sseClients.length}`);

    req.on('close', () => {
        sseClients = sseClients.filter(client => client !== res);
    });
});

// API Endpoint：觸發 9*9 乘法表程式
app.post('/api/start', (req, res) => {
    // 假設我們呼叫外部的 C 執行檔 (或是任何 CLI 工具)
    const cProcess = spawn('cmd', ['/c', 'echo 1*1=1 && timeout 1 >nul && echo 1*2=2']); // 這裡以 cmd 模擬輸出
    
    broadcastSSE('status', 'RUNNING');

    cProcess.stdout.on('data', (data) => {
        const output = data.toString().trim();
        if (output) {
            // 將程式的標準輸出推播給前端
            broadcastSSE('result', output);
        }
    });

    cProcess.on('close', (code) => {
        broadcastSSE('status', 'ENDED');
    });

    res.json({ success: true, message: 'Process started' });
});

app.listen(3000, () => {
    console.log('Server is running at http://localhost:3000');
});

4. 撰寫客戶端程式碼 (public/index.html)

建立 public/index.html，使用 EventSource 訂閱 /api/events 的推播，並透過按鈕呼叫 API 啟動背景任務：

<!DOCTYPE html>
<html lang="zh-TW">
<head>
    <meta charset="UTF-8">
    <title>9*9 乘法表 SSE 串流</title>
</head>
<body>
    <h1>9*9 乘法表 即時運算</h1>
    <button id="btn-start">開始運算</button>
    <p>系統狀態：<strong id="status">IDLE</strong></p>
    
    <h2>運算結果：</h2>
    <ul id="results"></ul>

    <script>
        const statusEl = document.getElementById('status');
        const resultsEl = document.getElementById('results');

        // 建立 SSE 連線
        const eventSource = new EventSource('/api/events');

        eventSource.onmessage = (event) => {
            const data = JSON.parse(event.data);
            
            if (data.type === 'status') {
                statusEl.textContent = data.payload;
            } else if (data.type === 'result') {
                const li = document.createElement('li');
                li.textContent = data.payload;
                resultsEl.appendChild(li);
            } else if (data.type === 'connection') {
                console.log('SSE 連線成功');
            }
        };

        // 按鈕觸發後端程式
        document.getElementById('btn-start').addEventListener('click', async () => {
            resultsEl.innerHTML = ''; // 清空先前的結果
            await fetch('/api/start', { method: 'POST' });
        });
    </script>
</body>
</html>

5. 執行與觀察

在終端機中啟動伺服器：

node server.js

開啟瀏覽器進入 http://localhost:3000，點擊「開始運算」按鈕。您會發現前端並沒有使用 setInterval 等待，而是依賴後端 spawn 程序的輸出進度，透過 SSE 將結果一行一行非同步地繪製到畫面上！這正是 SSE 結合背景工作最迷人的地方。

ℹ️

實際專案參考： 您可以將範例中的 spawn('cmd', ...) 替換為真實的 multiplication.exe 路徑，並且可以結合資料庫 (如 Knex.js + SQLite) 將每一次的乘法紀錄在背景寫入資料庫中。
