VS Code 建置 C 語言編譯環境指南

本附錄整理自內部知識庫的《VS Code 建置 C 語言環境》，主要協助開發者在 Windows 環境下安裝 C/C++ 編譯器 (MinGW)，以便編譯如 RTCP C99 引擎等執行檔。

1. 安裝 VS Code 與相關套件

首先確保您已安裝 Visual Studio Code。進入 VS Code 後，前往 Extensions (延伸模組) 頁面，安裝以下套件：

  • C/C++ (Microsoft 官方提供)
  • C/C++ Extension Pack
  • Code Runner (方便一鍵執行測試程式)

安裝完成後，建議重新啟動 VS Code 以確保套件正常載入。

2. 下載並安裝 MinGW 編譯器

在 Windows 下我們通常使用 MinGW (Minimalist GNU for Windows) 作為 C/C++ 的編譯工具：

  1. 前往 SourceForge 下載 MinGW Installation Manager。
  2. 執行安裝程式（建議保留預設安裝路徑 C:\MinGW）。
  3. 打開 MinGW Installation Manager，在基本套件清單中，勾選以下兩項並選擇 Mark for Installation：
    • mingw32-gcc-g++ (bin)：GCC 與 G++ 編譯器核心。
    • mingw32-gdb (bin)：GDB 除錯工具。
  4. 點擊左上角選單 Installation > Apply Changes，等待下載與安裝完成。

3. 配置 Windows 環境變數

為了能在命令提示字元 (CMD/PowerShell) 或 VS Code 終端機中直接呼叫 gcc，必須將 MinGW 的執行檔路徑加入系統的 Path 中：

  1. 按下 Windows 鍵，搜尋並開啟「編輯系統環境變數」。
  2. 點擊右下角的「環境變數」按鈕。
  3. 在「系統變數」清單中找到 Path，點擊「編輯」。
  4. 點擊「新增」，並填入 C:\MinGW\bin（若您安裝在其他路徑，請輸入對應的 bin 資料夾路徑）。
  5. 連續點擊「確定」儲存設定。
  6. 重要：請重新啟動電腦，或至少重新開啟所有終端機與 VS Code，讓環境變數生效。

4. 驗證編譯器安裝

開啟終端機 (PowerShell 或 CMD)，輸入以下指令檢查是否安裝成功：

gcc --version
g++ --version
gdb --version

如果成功印出版本資訊，代表您的 C/C++ 編譯環境已經準備就緒，可以開始編譯 C99 引擎了！
